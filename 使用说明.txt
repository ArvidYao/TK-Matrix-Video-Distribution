使用方法：
1. 双击「TK视频分发工具.app」→ 自动启动 Web 服务 + 打开浏览器
   （如遇"无法打开"安全提示，前往 系统设置→隐私与安全性→仍要打开）
2. 浏览器自动打开 http://localhost:5800 → 进入 Web 管理界面
3. 插入 iPhone → 点击「刷新」查看设备
4. 点击「开始分发」→ 自动完成上传、删除、重启
5. 等 90 秒后手机相册出现视频

备用启动：
- 双击「启动工具.command」→ 命令行模式启动（可查看日志）
- 手动运行：python3 web_app.py → 浏览器打开 localhost:5800

设置：
- 自动删除：分发后自动删除本地视频文件
- 清空旧视频：上传前先清空手机 DCIM 旧视频（默认关闭）
- 每台数量：每台手机分几个视频
- 批次大小：每批同时处理几台（推荐 4）

爆款素材（TikTok 爬虫）：
- 切换到「爆款素材」Tab，输入搜索关键词（如 #fyp、#viral）
- 点击「开始爬取」→ 实时显示爬取进度和日志
- 爬取结果以表格展示，包含视频标题、作者、播放量、时长等信息
- 批量勾选目标视频 → 点击「批量下载」→ 进度条显示下载状态
- 支持 CSV 导出：点击「导出 CSV」→ 保存搜索结果到本地
- 一键直达：点击「📂 一键直达」→ 在访达中打开下载目录
- 需要安装浏览器依赖：pip install playwright && python -m playwright install chromium

系统要求：
- macOS
- Python 3.8+
- 需安装依赖：pip install pymobiledevice3 flask pyyaml
               brew install libimobiledevice

文件说明：
- TK视频分发工具.app ─ 双击启动，自动打开 Web 管理界面
- web_app.py ─ Web 服务主程序（支持文案管理、隔空投送、爬虫）
- download_manager.py ─ 下载管理模块（批量下载、下载目录管理）
- tk_distributor_app.py ─ 桌面版主程序（PyQt6）
- tk_gui.py ─ 桌面版主程序（Tkinter）
- import_to_iphone.py ─ 核心传输逻辑
- clear_iphone_photos.py ─ 手机相册清理模块
- captions_manager.py ─ 文案管理模块
- airdrop_manager.py ─ 隔空投送管理模块
- airdrop_share_helper.py ─ AirDrop 辅助脚本（NSApplication 事件循环）
- tiktok_scraper.py ─ TikTok 爆款素材爬虫引擎
- tk-distributor.py ─ 命令行版
